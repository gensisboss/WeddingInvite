# Love story SVG article recreation

This project renders only the original SVG article body. The original nested SVG/SMIL markup and local image assets are kept unchanged.

## Run

```bash
npm install
npm run dev
```

Open the URL printed by Vite, usually `http://127.0.0.1:4173/`.

The production bundle can be checked with:

```bash
npm run build
npm run preview
```

The SVG's original click and animation behavior remains available. Text baked into the raster image backgrounds is intentionally not replaced.
